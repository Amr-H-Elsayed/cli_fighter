# CLI_fIGHTER
A Turn-based fighter game written in python and accessible through CLI

## Features:
- Turn-Based Combat: Tactical choices using simple keyboard commands.
- Randomized power range for the hits
- Chances for hits to miss
- Zero Dependencies: Runs natively with no extra installations.

## Installation & Run:
1. clone the repo: `git clone https://github.com/Amr-H-Elsayed/cli_fighter`, then `cd cli_war`
2. Run the Game: `python main.py`

## How to play:
##### - Enter names for Player-1 & Player-2
##### - Controls:
  1 = Normal Attack [Damage range: 8-15], [Hit success chance: 80%], [Stamina Cost = 5]
  2 = Critical Attack [Damage range: 25-35], [Hit success chance: 45%], [Stamina Cost = 15]
  3 = Heal [Heal range: 15-25], [Stamina Cost: 20]

## Cases:
   1. Normal defeat: Either players manages to defeat the other by depleting the opponents HP to Zero
   2. Finish Him Ending: Either player exhausts his own stamina, which grants the other player the chance to finish him in one shot.
